# L 型平面（從頭規劃）

## 法規結論（台灣《建築技術規則》設計施工編 §1）

| 項目 | 是否計入建築面積 | 說明 |
|------|------------------|------|
| L 型建築本體（外牆中心線以內） | **計入** | 建蔽率計算主體 |
| 無屋頂中庭（植栽／透光） | **不計** | 不在建築外牆投影內 |
| L 內側屋簷／陽臺外廊 ≤2m | **原則不計** | 屋簷、陽臺突出超過 2m 才自外緣回扣 2m；作成外牆外之屋簷／陽臺較穩妥 |
| 一般窗戶雨遮 | 另論 | 深度多按 1m，且構造形式有內政部令限制，不宜把整條外廊都叫「雨遮」 |

> 送審仍以開業建築師圖說與當地主管機關認定為準。

## 本案數字（示意）

- 基地約 **105.5㎡（31.9 坪）**，建蔽上限 60% → **63.3㎡**
- 建築面積（西翼 4.4×6.4 + 北翼 8.2×3.4 − 重疊）≈ **41.1㎡（建蔽約 39%）**
- 露天中庭 ≈ **11.4㎡**
- 臨路：固定車位 + 靈活空間
